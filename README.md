# TatvaSoft Internship Assignments

This repository contains all assignments completed during the TatvaSoft internship training program, covering frontend, backend, and database development.

## 📌 Scope

### 🌐 Frontend
- Angular assignments across 13 sessions  
- Hands-on setups, mini-projects (Todo, Shopping Cart)  
- Micro-frontend architecture (Module Federation)  
- Theory & Explore answers  

### ⚙️ Backend
- C# Console Applications (Student & Library Management)  
- Order Management System (Repository Pattern)  
- Consignment API with validations  
- .NET Core & Entity Framework Core  

### 🗄️ Database
- PostgreSQL scripts  
- Schema design (`homecare_db`, `training_db`)  
- Queries, Views, Stored Procedures, Triggers  
- Security configurations  

## 🛠️ Tech Stack
- **Frontend:** Angular (v16+), TypeScript, RxJS, Webpack Module Federation  
- **Backend:** C#, .NET Core, EF Core  
- **Database:** PostgreSQL, PL/pgSQL  

## 🎯 Purpose
This repository serves as a structured record of internship progress and fulfills mandatory TatvaSoft training submissions. It demonstrates practical implementation of concepts from basic development to advanced enterprise-level architecture.
